# Castwide

**Stream once. Go live everywhere.**

Castwide is a free multistream app for Windows. Send one stream from OBS or Streamlabs and Castwide relays it to Twitch, YouTube, Kick, Rumble, X, Facebook and TikTok.

This repository hosts Castwide's official releases and auto-update files. Download the latest version from [Releases](https://github.com/CastwideApp/castwide/releases/latest).

Castwide doesn't collect any data. Your keys and logins stay on your PC.
